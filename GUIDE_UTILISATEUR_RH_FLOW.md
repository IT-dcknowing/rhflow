# 📘 Guide d'Utilisation : RH Flow

Ce guide vous accompagne pas à pas dans la configuration et l'utilisation quotidienne de votre plateforme RH Flow, de la création de votre entreprise à l'édition des bulletins de paie.

---

## 1. Configuration de l'Entreprise (Le Socle)
*Avant toute chose, structurez votre environnement de travail.*

### A. Paramètres de base
- **Accès** : `Configuration Entreprise` > `Paramètres Entreprise`.
- **Action** : Renseignez le nom, l'adresse, le logo et les informations fiscales (NIF, RCCM). Ces informations apparaîtront sur vos bulletins et documents officiels.

### B. Structure Organisationnelle
- **Sièges et Succursales** : Créez vos différents lieux physiques.
- **Services (Départements)** : Créez vos unités (RH, Finance, IT, etc.).
- **Postes (Designations)** : Définissez les intitulés de postes.

### C. Système de Présence
- **Accès** : `Configuration Entreprise` > `Système de présence`.
- **Action** : Choisissez entre le pointage manuel (saisie par le RH) ou le pointage par scan de QrCode.

---

## 2. Gestion des Employés (Le Cœur)
*Configurez vos talents et leurs conditions contractuelles.*

### A. Création d'un Employé
- **Accès** : `Gestion des Employés` > `Listing des employés`.
- **Action** : Cliquez sur "Créer". Remplissez les onglets :
    - **Personnel** : État civil, contacts.
    - **Bancaire** : RIB pour les virements ou Mobile Money.
    - **Document** : Téléchargez les scans (CNI, diplômes).

### B. Gestion des Contrats
- **Accès** : `Gestion des Employés` > `Gestion des Contrats`.
- **Action** : Définissez le type de contrat (CDI, CDD, etc.), la date d'effet et le salaire de base. Un employé doit avoir un contrat actif pour être inclus dans la paie.

---

## 3. Cycle de Paie (L'Exécution)
*Suivez ce flux mensuel pour une paie sans erreur.*

### Étape 1 : Vérification de la Période
- **Accès** : `Gestion de Paie` > `Listing des exercices`.
- **Vérification** : Assurez-vous que le mois concerné est bien "Ouvert".

### Étape 2 : Saisie des Variables (Primes & Retenues)
- **Primes (Brut)** : Saisissez les bonus dans `Éléments du brut`.
- **Retenues** : Saisissez les avances sur salaire dans `Retenues salaire`.
- **Prêts** : Gérez les remboursements longs dans `Prêts`.

### Étape 3 : Calcul Global
- **Accès** : `Gestion de Paie` > `Calcul salaire`.
- **Action** : Cliquez sur "Lancer le calcul". RH Flow traite automatiquement les cotisations (CNPS, etc.) et l'impôt selon la législation en vigueur.

---

## 4. Reporting et Documents (La Finalisation)
*Éditez vos preuves et vos états réglementaires.*

### A. Les Bulletins de Paie
- **Action** : Dans `Calcul salaire`, cliquez sur l'icône "Œil" ou "Télécharger" pour obtenir le bulletin de chaque employé.

### B. Les États de Paie (Comptabilité)
- **Livre de Paie** : `Etats et Déclarations` > `Livre de paie mensuel`. Indispensable pour votre lettrage comptable.
- **Résumé des paies** : Pour une vue d'ensemble rapide des coûts totaux.

### C. Déclarations Sociales
- **Accès** : `Etats et Déclarations` > `Déclarations Mensuelles`.
- **Action** : Exportez les fichiers pour vos télédéclarations.

---

## 🤖 Astuce : Utiliser l'Assistant IA
Si vous avez un doute sur un calcul de congé ou une règle fiscale :
1. Cliquez sur le bouton **Assistant IA** dans la sidebar.
2. Posez votre question (ex: "Combien de jours de congés par mois pour un apprenti ?").
3. L'IA analyse votre base de données et la loi pour vous répondre instantanément.
